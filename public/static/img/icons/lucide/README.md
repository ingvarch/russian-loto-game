# Vendored Lucide icons

Source: https://lucide.dev, package `lucide-static@1.42.0`, ISC (see LICENSE).

Only the icons the app actually uses are kept here. They are the reference
copies: the markup is inlined at the point of use so the pages need no icon
font, no sprite fetch and no JavaScript to paint a tab bar. When an icon
changes here, update the inlined copy too.

Inlined with `stroke-width="1.75"` rather than Lucide's own `2`, so the
weight reads closer to SF Symbols at the sizes this app uses.
