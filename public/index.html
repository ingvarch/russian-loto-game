Русское лото

Live-игра для ведущего, табло для игроков.

Формат JSON

Колода — массив карт. Каждая карта имеет четыре поля: seq (порядковый номер), cid (идентификатор), numbers (15 чисел из 1..90), rows (3×9, ровно 5 чисел в строке, остальное — null). Каждое число должно лежать в своей колонке: 1..9, 10..19, ..., 80..90.

Принимаются три формы: [ ... ], { "cards": [ ... ] } и сырой ~/.russian-loto/printed.json из CLI (там cid лежит ключом — лендинг разворачивает его в поле автоматически). 

[
  {
    "seq": 1,
    "cid": "abcdef01",
    "numbers": [1, 2, 11, 12, 24, 25, 30, 31, 40, 50, 51, 70, 71, 80, 81],
    "rows": [
      [1,    11,   24,   30,   null, null, null, null, 80],
      [2,    null, 25,   null, 40,   50,   null, 70,   null],
      [null, 12,   null, 31,   null, 51,   null, 71,   81]
    ]
  }
]
